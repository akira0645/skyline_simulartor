# 目前實作與驗證範圍

更新：2026-11-15。這份文件描述已寫入程式的行為；`superpowers/specs` 保留完整願景，不能將其中所有項目視為已完成。

## 大型地塊與造訪

- `FacilityAccess` 統一查詢占地與接路入口。2×2 設施按主格記錄目的地，路徑則終止於實際可達的外緣入口；等距入口依人物與日期分流。
- 四格設施共用訪客與本月人次。連片公園加總群組，集合住宅顯示整群成人住戶與有效容量，下方保留所選單戶的住戶資料。
- `CivicVisits` 安排行程，`VisitSystem` 推進前往、使用、轉診及返家。人物到達才記一次人次，取消和回程不計。鏡頭位置與動畫幀不會新增到達事件；渲染器只讀取設施行程。
- 同住居民可各自出行；已有行程的人不重複尋路。拆路、拆設施、住戶離開會取消相關行程。舊存檔主格及附屬格人次合併，不能還原舊版已重複計算的歷史。
- 追加調整：訪客面板分為「使用中」與「前往中」，分別顯示人數與名單，返程不顯示。短活動也能在兩次核心更新之間顯示使用狀態；這種顯示插值不會重複增加人次。
- 名單預設收合，只顯示人數；點開以兩欄列出姓名，長名單獨立捲動。點姓名可查看人物，切換地塊會收合，0 人不提供空的展開操作。
- 居民完成返家後，當天可以安排下一個活動。步行每格 0.08 tick；辦事約 0.2 tick、閱讀／購物／散步約 0.5 tick、展覽 0.75 tick、較長活動 1 tick。安排前檢查營業結束、上班通勤與 23:00 休息時間；銀行開放時段調為 09:00–13:00。
- 多次活動會增加尋路次數，因此依地圖版本快取附近設施與入口路徑，拆路與改建時自動失效。交友使用真正重疊的活動時間，短活動不會因剛好落在兩次更新之間而漏算，也不把先後抵達算成碰面。

## 人物、家庭與天氣

- 成人保存永久 ID、姓名、出生時間、特質與偏好。搬家方法保留身分、財產及朋友；目前沒有玩家指定搬家的介面。
- 共同停留在設施的人會增加熟悉度，一對人物每天最多增加一次，每人最多 24 位聯絡人。人物卡可點選認識的人。
- 舊版顯示的小孩在遷移時固定成資料；新家庭不再因成人增加而憑空出現小孩。兒童占用新增遷入的住房名額，總人口包含兒童，既有成人稅收與解鎖口徑維持原樣。
- 18 歲保留原身分轉為成人，提供 30 日求職／居住緩衝；65 歲退休、不再尋職，基本生活費視為由外部年金支應。
- 生病、重症、治療、康復、退休及離世記入最近 100 筆人生事件。一般疾病可以休養恢復；重症需抵達醫院才開始療程。這些數值是遊戲規則。
- 同住、關係親密且有空間的適齡成人，可能安排 270 遊戲日後迎接孩子。這是首版生育判定，尚無伴侶／家庭帳戶和完整育兒意願介面。
- 監護人離開或離世後，兒童安排至有空間的成人家庭；沒有空間則保留在城外照護狀態，不悄悄刪除。遺留現金交給同住的存活成人；尚無完整遺產帳簿。
- 天氣由種子與日期決定，有晴、雨、大雨及次日預報。雨天減少非必要戶外行程，短途自行車通勤可改步行，大眾運輸意願增加且仍受實際運能限制；必要就醫不受休閒出門頻率限制。

## 存檔與時間

- 存檔格式 v6，可讀 v1–v5；包含行程、當日活動紀錄、不安、任務冷卻、人物身分、關係與人生狀態。解析失敗不替換目前城市。
- `AutosaveSession` 負責首次讀取、寫入序列、錯誤及最後成功時間。首次讀取失敗會停止自動覆寫，仍可使用手動另存與備份。
- 自動存檔與前次備份使用同一個 IndexedDB transaction 寫入；手動欄位不受影響。讀取失敗可按「重試讀取」；成功載入手動存檔或備份後恢復自動存檔，首次恢復寫入保留原備份。
- 支援暫停、0.25×、0.5×、1×、2×、4×；慢速同步影響模擬時間與人物動畫。設施排程在三小時的經濟更新內逐小時執行。
- 隱藏分頁暫停、不補算離線時間。短暫卡頓每次最多補 4 tick，長於 15 秒的缺口則暫停並提示。

## 架構與檢查

新增的邊界包括 `FacilityAccess`、`CivicVisits`、`VisitSystem`、`ResidentIdentity`、`Relationships`、`LifeSystem`、`Weather`、`SavedVisits`、`SavedLife` 與 `AutosaveSession`。`BuildingSystem` 仍負責協調舊經濟／就業系統，`App` 的面板尚未完全拆分。

```sh
npm run test:fast
npm run test:simulation
npm test
npm run build
```

`npm test` 依序執行兩組。年度物價等長期模擬單工執行，使用獨立 60 秒上限；快測試仍維持 30 秒上限。生命系統有百年重播測試；城市平衡測試涵蓋小、中、大三城及兩個種子、月度變化、存讀檔後繼續模擬與道路恢復。這不代表已驗證整座城市的百年財政平衡。

## 尚未完成的願景與驗收

- 家庭獨立 ID、伴侶、邀約／探病、學歷持久化、完整遺產帳目、拆房後成人安置、哀傷與個人回憶。
- 設施座位容量、候診／預約、兒童獨立行程、交通客滿候車與全種類主活動統一。
- 世代加速模式、分段氣象、雨中途中改道。現在是每日天氣與原本每年增齡。
- 設施間可連續走訪，單趟最多三個場所，檢查營業與返家時間；同日避免重複一般活動，就醫例外。人物卡顯示出門原因與最多八筆當日活動。尚無行程編輯器；通勤仍有自己的動畫模型，設施行人未接上交通號誌等待。
- 瀏覽器自動驗收未完成：本次電腦操作工具無法確認 Windows 瀏覽器網址並停止操作，因此沒有假稱已驗證實際點擊、縮放、分頁恢復或 IndexedDB 真實配額錯誤。

手動驗收順序：建立道路旁的四種新建築 → 點四個附屬格比較訪客與月人次 → 遠移鏡頭後返回 → 在人物卡檢查朋友／健康／雨天原因 → 存讀檔 → 暫停後切換分頁 → 從自動備份恢復。正式建置目前仍有主 bundle 超過 500 KB 的提示。
