# 素材進度

目前重畫並接入近看顯示的建築為 12 種：住宅、公寓、商店、辦公樓、工廠、小學、發電廠、水塔、消防局、警察局、診所、倉庫。人物四方向六幀、汽車與貨車 16 方向、闊葉樹沿用同一批程式像素來源。原生圖、自動檢查及獨立目視報告都在本目錄。

以下仍沿用既有程式素材，不能算作本輪全部重畫完成。依 `TileRenderer.ts` 的圖集映射及 `tools/draw_tiles.py` 盤點，後續以功能完整的一組逐批處理，避免把同一棟原型硬套到不同設施。

| 組別 | 待提升的素材 | 檢查重點 |
| --- | --- | --- |
| 大型公共建築 | 醫院、大學、博物館、體育場 | 保留 2×2 占地、入口、屋頂輪廓與樓層關係 |
| 交通 | 公車站、捷運入口、公車、救援車輛 | 站點辨識、車門、前後結構、各車種長寬 |
| 商業與地標 | 大型商場、賭場、遊樂園、廟宇、電影院、KTV | 保留用途與輪廓，避免只換色 |
| 教育與民生 | 高中、圖書館、游泳池，以及市政／照護／社區專用建築 | 招牌、入口、設備與設施細節 |
| 住宅與產業變體 | 大樓、住宅社區、各類住宅三等級、食品與重工業的專屬變體 | 隨等級與種類改變體量，保留各城市造型差異 |
| 景觀與街道 | 公園設備、針葉樹、灌木、農場、路燈與站牌等 | 與新人物的比例、遮擋、材質與整數像素邊緣 |

已重畫的警局與消防局標誌經第二次複查；小尺寸下的電廠標誌和藍色車窗對比仍有可改進之處，詳見獨立報告。
