# 頂欄排版修正

依使用者提供的截圖，原本固定高度單列頂欄無法容納新增的慢速按鈕，按鈕換行後溢出，資訊與操作也缺少分區。

採用兩層頂欄：上層是天氣、資金、人口及需求；下層是日期、單排速度選擇與城市操作。保留既有像素配色，按鈕改為細邊框，速度組採連續分段樣式。窄於 60rem 時城市操作另起一列，窄於 34rem 時日期與速度再分列，所有倍率保持在同一排；極窄的資訊列允許水平捲動。

頂欄高度使用共用變數，通知、事件卡、資料面板及其開關隨之位移。移除互相覆蓋的舊頂欄規則。此次只調整排版，不改模擬邏輯。

驗收：正式建置與差異空白檢查；瀏覽器工具只有無法連線本機服務的內嵌瀏覽器，因此沒有宣稱完成視覺驗收。
