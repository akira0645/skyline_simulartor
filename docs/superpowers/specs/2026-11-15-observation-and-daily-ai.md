# 慢速觀察與居民日常細節

使用者已同意後續工作，並要求可放慢速度、把人物 AI 做得更細。本批直接實作以下可觀察且可測試的行為。

- 加入 0.25×／0.5×，與原有暫停、1×、2×、4×共存。模擬和渲染共用倍率，不只讓人物動畫變慢。暫停與切分頁保留所選速度。
- 經濟 tick 仍為三小時；每個 tick 內依小時處理居民行程，確實涵蓋 07:00 上學及 16:00 托育。子時段出發、到達與訪次只結算一次。
- 已出門的居民完成活動時，若當下有可達、營業中且不影響工作／睡眠的不同活動，可以直接從現有入口前往下一處；一次外出最多三個活動，之後返家。醫療與康復不接續休閒。
- 人物卡顯示真實排程原因與今日出發／抵達紀錄。每人最多保留八筆當日活動；同類一般活動一天不反覆安排，急病就醫例外。資料隨存檔保留，以永久人物 ID 關聯。
- 存檔失敗可重試讀取；成功讀取其他欄位／備份後恢復自動存檔，首次寫入不得用損壞的原自動檔覆蓋已存在的備份。
- 訪客區塊獨立成元件，維持原本的人數展開行為。嘗試可用的瀏覽器驗收；若工具仍不可用，明確記錄未驗收，不以建置代替畫面驗收。

本批不加入外部語言模型呼叫，也不宣稱已完成親友邀約、候診容量、完整家庭安置或全部交通號誌時序。
