# 汽車與建築的近看細節

以 v0.6.0 為基礎，依使用者同意的「一款汽車先試、放大顯示更多細節」範圍實作；開始後使用者追加建築，因此本輪一併涵蓋四個城市風格的既有建築。

## 建築細節

- 沿用可編輯的既有建築生成素材，由 `tools/detail-buildings.py` 離線產生四套 64px 圖塊（原本 32px）。沒有改用假 3D 相機或重畫整個地圖。
- 1.75 倍開始選用近看圖集，普通與 2×2 大型建築同時切換。圖塊在世界中的尺寸、占地、透明輪廓、陰影範圍與招牌符號保持一致；半世界像素的細節由 nearest 過濾顯示。
- 細節依原圖已有結構加入：玻璃窗框與反光、木門門把、斜屋頂瓦縫、紐約磚縫、工業金屬板接縫，以及空白平屋頂上的通風設備。保留經典、舊金山、加州、紐約原配色。
- 共處理 520 個非空建築 frame（四套配色各 130 個），涵蓋住宅、商店、辦公室、工廠、倉庫、公共設施與大型建築。增加細節不代表每個 frame 都新增相同設備；例如水塔、球場、寺廟等不硬加空調。
- 對生成結果逐像素驗證 alpha 等於原圖 nearest 放大的 alpha，防止建築輪廓擴張。道路與空地仍為原圖的 nearest 放大副本。
- 近看時將底圖快取解析度提高至每個世界像素兩點，否則即使載入 64px 圖塊，也會在快取時丟失半像素窗框與屋瓦細節。縮小時保留原有 1、0.5、0.25 快取解析度。

## 顯示與素材

- 用 sprite-stacking 的四視圖切片流程製作一款日常掀背車。保留原始四視圖、切片與檢查圖，方便重製。
- 將切片離線烘焙為 16 方向圖集。切片不在遊戲每幀繪製；沿用 PixiJS 的 Graphics 紋理繪製，沒有第二套遊戲畫布。
- 小於 0.85 倍維持原本簡化輪廓；0.85 至 1.75 倍維持既有普通車；從 1.75 倍顯示四倍素材密度的細節車。尺寸仍為 10×6、12×6、13×7 世界像素，切換前後以同一地面中心定位。
- 一款車分成原有三種汽車尺寸，沿用五種一般車色、三種高級車色、黃色計程車；計程車有車頂燈，高級車有金色裝飾。腳踏車、機車與特殊車輛沿用現有圖形。
- 車窗、車頂、頭尾燈與輪胎要在最大 3 倍縮放時可辨識；先確認自然遊戲尺寸，再用放大圖檢查素材瑕疵。

## 行進方向與整合

- 行駛中的車從路徑前後取樣差計算 heading，映射至最接近的 16 方向，禁止僅用橫直旗標決定車頭。
- 停車使用路邊相鄰路段方向；停車場兩排向外停。繪製不影響通勤時間、路權、排隊、存檔、貨運和模擬亂數。
- 圖集與所有方向的地面支點一致，禁止對不同方向的可見內容單獨裁邊再置中；沿用浮點世界位置，交由現有相機縮放。
- 圖集載入與既有素材一起等待，使用 nearest 過濾；快取 frame texture，避免每輛車每幀建立貼圖。

## 驗收

- 方向映射涵蓋東西南北、斜角、角度環繞，零位移取樣有穩定退路。
- 檢查輸出的圖集尺寸、16 個方向與同一支點；目視轉盤整圈，排除閃爍或偏心。
- 在瀏覽器中用同一城市檢查 1、1.75、3 倍畫面、路邊及停車場；確認新素材實際被使用、車頭隨行進方向、沒有遺失貼圖或主控台錯誤。
- 執行相關繪圖測試、一般測試與建置；純視覺變更不改模擬規則。

## 取捨

直接細化既有矩形最省素材成本，但無法驗證 sprite-stacking。即時疊片可連續旋轉，但對城市大量車輛增加每幀工作。本次採離線圖集，在現有渲染器內驗證效果及縮放細節；16 方向是素材成本與轉向辨識度的折衷。

## 實作與驗證結果

- 一般測試：51 個檔案、195 項通過（單 worker）。初次同時執行建置時兩項 demoCity 測試超時，分開重跑與完整單 worker 重跑皆通過；沒有修改測試期限或模擬規則。
- 追加快取解析度測試後，繪圖測試：10 個檔案、32 項通過。TypeScript 檢查與正式版 Vite 建置通過；原有 bundle 大小提示仍存在。
- 無介面 Edge 實際載入加州、紐約、舊金山三座示範城市，各驗證 1、1.74、1.76、3 倍，共 12 組。確認 1.74 倍仍使用 32px 建築與 1 倍快取，1.76／3 倍使用 64px 建築與 2 倍快取，且實際繪製了細節汽車。無瀏覽器執行錯誤。
- 檢查切片、多方向圖與實際遊戲截圖，包括停車場上、下兩排及四種城市建築對照。現行素材已依使用者要求改為程式繪製，像素來源與重製指令在 `docs/design-assets/car/README.md` 及 `docs/design-assets/handmade/README.md`；瀏覽器截圖及 `verification.json` 在忽略版控的 `work/car-preview/`。
- 新增執行時 PNG 合計約 1.30 MB；汽車逐方向預烘焙，建築維持既有底圖快取。尚未做不同顯示卡上的效能比較，沒有宣稱特定 FPS。
