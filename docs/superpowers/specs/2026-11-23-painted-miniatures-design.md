# 保留已認可人物／單車風格及性別對應

使用者先以既有建築概念圖說明精緻感，之後明確附上 `docs/design-assets/residents/residents-contact.png` 與 `docs/design-assets/bicycle/bicycle-turntable.png`，表示這兩張原本的感覺可以。以最後的直接參考為準：人物／單車保留原有比例、配色、尺寸與像素手繪感，只修正性別對應與實際顯示落差，不全套重畫。不使用影像生成。

- 人物：四款男性／四款女性外觀，三年齡與既有四方向六步態。僅微調女性肩線、臉型、鬢髮與髮飾，原男性圖像保持不變；頭像、地圖與騎士共用身分。
- 身分：新增持久性別欄位。新居民與內建姓名目錄一起生成；舊存檔的內建姓名按目錄分類補齊，其餘以固定 ID 補齊，不對任意名字猜測。保留既有姓名、年齡、工作及人際關係；性別不影響能力或生活規則。出生、成年、搬家及存讀檔均保留。v12 支援舊 v1–11。
- 顯示：人物從 1× 顯示完整素材，腳踏車從 0.85× 顯示十六方向圖集；取消以前一律等到 1.75× 才顯示的限制。更遠的視角仍簡化。騎車與走路依原本天氣、路程及持有交通工具規則，不把機車冒充單車。
- 單車：保留原三角車架、輪距、騎姿與十六方向，補女性眼鏡騎士的髮型／眼鏡對應，踩踏仍依實際路程、停車無騎士；按需載入與共享快取不變。
- 建築：這一批僅修正人物與單車，建築圖集維持原樣。後續建築精緻感另按原圖輪廓、各棟特色及四種城市配色逐批處理，不能因此把已認可的人物／單車換成另一種風格。
- 記憶體：人物 3072×336、頭像 384×144、單車 1024×3200，解碼尺寸與原批次相同，未擴大圖集或增加近看城市圖集。
- 驗收：原生尺寸與放大樣張、四方向人物、十六方向單車、性別／外觀一致與舊存檔遷移、遊戲內實際顯示。視覺評審與回歸完成後再推送。
