# 人物外觀、人物卡頭像與單車

這是 `2026-11-23-residents-art-and-travel-plan.md` 中人物／單車部分的檢查點，時間統一仍待下一步。建築沿用 Claude 的原圖細化流程，未重畫或覆蓋。

## 人物與頭像

- `tools/draw_residents.py` 沿用原先的程式像素 Canvas、四方向與六步行姿勢，另畫髮型、臉、配件和年齡比例。8 種外觀 × 兒童／成人／長者，共 24 組，並非 24 種完全不同的身體輪廓。
- `residentAppearance(seed, id, age)` 依固定居民 ID 選造型，年齡選身形。以 `BuildingSystem.residentLook` 輕量取得地圖人物身分，人物卡用同一份對應；搬家、重排和讀檔不依住址或繪製索引換臉。不新增存檔欄位。
- 地圖 672 格為 3072×336 圖集，RGBA 約 3.94 MiB；頭像 384×144，約 0.21 MiB，只在人物卡使用。未以原地圖的小頭裁切放大，頭像直接在 48×48 畫臉與肩膀。
- 人物卡新增頭像，切入或切換人物時重設資料面板捲動，避免頭像藏在捲動範圍上方。舊的低倍率簡化人物也對應衣色／膚色。

## 單車

- `tools/draw_bicycles.py` 以同一份 44 層體積定義輪圈、輻條、三角車架、前叉、鏈條、坐墊、把手、前燈與尾反光片，生成四視圖、切片與16方向。騎士依相同外觀表取膚色、衣色與髮色。
- 兩種相反踏板姿勢共用 pivot `(32,45)`；車架與燈不整體位移，騎士腿部與輻條改變。踩踏相位由實際路程決定，停住不按牆鐘繼續踩；停車版固定第一姿勢且沒有騎士。
- 64px 原生幀，squash 0.8、slice spacing 0.75，修正初稿沿用汽車高度投影而令輪圈過扁的問題。共 800 格，1024×3200、RGBA 12.5 MiB；僅在可見且放大至 1.75× 的單車需要時非同步載入，跨渲染器使用共用引用計數，離開後卸載。
- 像素細節不改車身碰撞尺寸、道路跟車與通行權；沿用既有單層 Pixi Graphics，沒有另建 canvas 疊在遊戲上。

## 驗證

- 渲染與居民對應測試 20 檔／65 項通過；涵蓋造型穩定、年齡組別、圖集所有格座標、同一 ID 搬家／存讀檔後仍與人物卡一致、單車前後方向及距離相位，停車版固定姿勢。
- 正式建置、最終 TypeScript／Vite 建置通過，原有大型 bundle 提示保留。本輪尚未改時間，不冒稱慢速時鐘完成。
- 瀏覽器實際點開居民，確認頭像和姓名顯示、切換資料卡捲動歸零；人物與單車四方向用實際 StreetArt／BicycleSprites 預覽。截圖見 `docs/design-assets/residents/person-card.jpg` 與 `people-and-bicycles.jpg`，無 JavaScript 錯誤。
- 依 pixel-art-studio 進行獨立評圖，人物與單車均 PASS。人物 checker 抽樣平均 73.33，人工評分 85；checker 的平塗材質／輪廓陰影警告沒有隱藏，也不把人工分數冒稱自動分數。所有 672 個人物格與 800 個單車格無空白或碰框。
- 詳細限制見各自 `review.json`：部分髮型在小尺寸接近，長者灰髮和眼鏡使差異減少；單車騎士頭部配件簡化，部分側輪因投影與遮擋較扁。兒童造型供已有／後續人物呈現使用，本輪沒有另加兒童獨立活動或資料卡系統。

重建：先 `python tools/draw_residents.py`，再 `python tools/draw_bicycles.py`。圖集與預覽皆由程式繪製，未使用影像生成模型。
