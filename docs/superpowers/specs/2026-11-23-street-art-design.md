# 第一階段：完整街景的美術標準

使用者已確認盤點與階段順序。本階段重製六種代表建築（獨棟住宅、公寓、街角商店、辦公樓、工廠、小學），加上闊葉樹、行人、貨車；將它們和已完成的汽車放在同一場景驗收，再作為其餘美術的依據。

## 風格與素材

- 固定斜俯視、正面朝畫面下方，建築邊線平行畫面座標，避免等角投影與現有方格道路衝突。
- 左上方受光，冷色陰影、溫暖亮面。玻璃、磚、金屬、木材具有各自的明暗與材質特徵。
- 使用者要求程式繪製並保留手繪感：汽車、貨車、六種建築、樹木與人物均由 `tools/draw-handmade.py` 重作，保存像素 JSON 與本機 pixel-art-studio renderer 的輸出，沒有使用影像模型。舊生成原型封存於 `docs/design-assets/generated-archive/`，不進入遊戲素材流程。
- 建築採 64×64 原生格、有限色盤、材質分面與少量不對稱裝飾，強調手工像素群組與可辨識的筆觸，不以隨機紋理或圖片像素化取代繪製。
- 固定物件採預烘焙圖塊；貨車沿用 sprite-stacking 四視圖及方向烘焙。行人使用方向與步態選取圖格，樹木使用有厚度與枝葉層次的新圖。
- 普通建築世界占地不變。高密度圖像的近看快取要保留其解析度。增加至最高 6 倍縮放，方便檢查新素材與城市局部；縮小維持清楚輪廓。

## 整合

- 重製的六種建築先替換對應代表圖格；未完成的類型繼續使用既有素材，不將它們標成已重製。
- 同一套代表建築保留四種城市配色。原型的幾何與材質標準先確認，全面重製時再做各城市獨立建築語彙。
- 樹木與行人接入現有地圖和人物繪製流程。貨車保留路線顏色、位置、方向、選取與運營資訊。
- 預覽使用同一套 PixiJS 素材與繪圖元件，在獨立的開發預覽頁排列代表街景；不建立第二套遊戲渲染管線。
- 不改模擬、存檔或經濟規則。

## 驗收

- 同一街景比較六種建築、樹、人、汽車及貨車的比例、光源與清晰度。
- 1、1.75、3、6 倍顯示均可辨識；建築貼地、沒有白底、沒有裁切；車頭與行進方向一致。
- 瀏覽器檢查實際遊戲與街景預覽，保存可供使用者審閱的截圖。完成相關測試、TypeScript 檢查及建置後交付。

## 程式繪製版驗收結果

- 第一批完成：汽車、貨車、六種代表建築、闊葉樹、四方向人物及六幀行走。保留四種城市配色、車道尺寸與原有模擬規則。
- `npm run test:fast -- --maxWorkers 1`：54 個檔案、203 項通過。繪圖相關測試 12 個檔案、38 項通過，包含陰影透明度污染貼圖的回歸，以及人物六幀循環與固定支點。
- TypeScript 檢查、完整 `npm run build`，以及透明度修正後的正式 Vite 建置通過。原有 bundle 大小提示仍存在；未宣稱特定硬體 FPS。
- 三座城市各檢查 1、1.74、1.76、3、6 倍，共 15 組，確認代表素材實際使用、低倍率不繪製近看素材、快取解析度正確。獨立街景頁再驗證 1、3、6 倍與播放／暫停，無瀏覽器執行錯誤。
- 43 張原生像素圖保留完整自動品質結果；未超出 40 色、孤立像素比例或意外雙線上限。20 個被標記結果保留原警告，由獨立審閱逐項判讀；結論 PASS／87 分。陰影啟發式誤判、人物後腿雙線、窄色相與樹冠形狀限制未隱藏。
- 最終截圖：`docs/design-assets/handmade/street-review.png`。像素規格、來源聲明、重製流程及自動／獨立審閱結果同在 `docs/design-assets/handmade/`。先前生成來源僅封存於被忽略的 `generated-archive/`，不再進入遊戲或烘焙流程。
