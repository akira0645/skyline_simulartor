# 平板地圖縮放修正

使用者回報平板無法放大查看素材細節，並確認直接修正。原因是地圖雖已允許 0.25–6 倍縮放，輸入只監聽滑鼠滾輪；第二根手指會被既有拖曳邏輯忽略，canvas 的 touch-action 又停用了瀏覽器原生手勢。

## 操作與界線

- 兩指張開／捏合縮放，以移動中的兩指中點為中心，同時支援雙指移動。沿用 0.25–6 倍上限與地圖邊界。
- 畫面左上方提供垂直排列的「＋／－」，每個可點按區至少 44×44 CSS 像素，使用地圖中心放大，保留滑鼠滾輪。
- 第二根手指加入時清除單指建造／拆除／選取預覽，直到所有手指離開才恢復一般工具，避免抬起一指後誤蓋建築。取消、失去 pointer capture、第三根手指加入或離開都會重新依目前手指位置計算，不沿用舊距離。
- 單指查看、拖曳與建造維持原有操作。縮放只改視角，不改城市資料或存檔格式。

## 驗證

Camera 與 MapPinch 的 6 項測試涵蓋中點錨定、上限、雙指平移、手勢取消後抑制工具、第三指替換與退化距離；連同素材顯示回歸共 4 檔／10 項通過。TypeScript 與正式建置通過，既有大型 bundle 提示保留。瀏覽器在 1024×768、768×1024 尺寸已實際點按放大至素材細節並縮小，直向訊息列遮擋按鈕已修正；驗收截圖見 `docs/design-assets/tablet/map-zoom-1024.jpg`。原生多點觸控尚待實體平板確認，不能把單指點按驗收當作實機雙指驗收。
