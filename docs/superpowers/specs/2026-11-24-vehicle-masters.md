# 交通工具精緻原稿與縮放一致性

使用者已確認「先完成精緻原稿，再縮小修正可讀性」，並指示開始。沿用已認可的人物與腳踏車配色、比例，以程式像素素材和 sprite stacking 製作，不使用影像生成。

本批完成居民交通工具（腳踏車、機車與三個汽車等級）。汽車從完整立體原稿建立輪拱、座艙、車窗與前後結構；腳踏車修整輪圈、車架與騎姿；補上目前仍只有矩形的機車。原稿烘焙為固定支點的 16 方向圖集，再縮小至遊戲所需密度；普通倍率和放大使用同一圖集，不在放大時替換成不同車型。

維持現有世界尺寸、人物外觀對應、車速、碰撞、行程、交通規則與存檔。汽車與腳踏車既有圖集尺寸不增加；機車使用獨立且按需載入的圖集，離開城市時釋放引用。每個物件仍只有一次貼圖繪製，不增加即時疊片或第二個遊戲畫布。

驗收先看原稿與完整方向，再看同素材在 1×、3×、6×，檢查接地、車頭朝向、各角度裁切與機車腳踏板。另在真正 CityRenderer 中驗證單車、機車、汽車都使用新素材。執行相關回歸測試與正式打包，附素材大小及量測限制。建築、貨車與大眾運輸為後續批次，不將本輪記為已完成全城美術。

實作順序：立體原稿與離線烘焙 → 原稿／縮小對照 → 圖集接入 → 實際城市檢查 → 報告與推送。選用同一份烘焙圖集，避免兩套 LOD 外形跳變；不採每幀疊片，以保留上一輪效能改善。
